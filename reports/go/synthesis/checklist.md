# Canonical Go Language-Feature Checklist

## Scope and reconciliation rules

This checklist targets the official Go `gc` toolchain in module mode. The canonical baseline is Go 1.25 because the Fable report supplies primary-release evidence through that version. Every version-sensitive item still requires the older language-version boundary named by the item; installing a newer toolchain does not erase semantics selected by a module or file language version. Alternative implementations, unsupported targets, experiments, and moving tool directives are conditional or unresolved rather than portable requirements.

Each row is one materially observable behavior. “Obligation” states what a fixture must demonstrate. “Variants and failures” are part of the item, not optional notes. Classification uses the four requested classes. `C`, `F`, and `G` mean the Codex, Fable, and Google input reports.
