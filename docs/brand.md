# Brand assets

The files in `docs/user/assets/brand/` are generated by `task brand` from `scripts/brand.py`. Do not edit these files by hand.

"Light" and "dark" name the background the asset is drawn for.

| File | Use |
| --- | --- |
| `logo-light.svg`, `logo-dark.svg` | Mark and wordmark, horizontal. README header. |
| `logo.svg` | Lockup that follows `prefers-color-scheme`. |
| `mark-light.svg`, `mark-dark.svg` | Mark only, square. wyrd.foo `logo` and `logo-dark`. |
| `mark.svg` | Mark only, follows `prefers-color-scheme`. |
| `mark-light-512.png`, `mark-dark-512.png` | Mark only, raster, transparent. |
| `favicon.svg` | Reduced-detail mark for small sizes. wyrd.foo `favicon`. |
| `favicon.ico`, `favicon-32.png` | 16, 32 and 48 px raster favicon, light-background ink. |
| `app-icon.svg`, `apple-touch-icon.png`, `icon-192.png`, `icon-512.png` | Reduced-detail mark on a solid tile. |
| `social-image.svg`, `social-image.png` | 1200 × 630 card. wyrd.foo `social-image`. |
| `social-preview.svg`, `social-preview.png` | 1280 × 640 GitHub repository social preview. |

The reduced-detail mark keeps the iris, pupil and axis traces. Lids and minor pads do not hold up below about 64 px.
